GeneralAIPlatformsJiraGit hostsPrivacy & diagnostics

Git hosts

No host identities yet. Today every remote uses your SSH agent and ~/.ssh/config, plus the app-wide key from General when one is set. Add a host to use a different key or HTTPS user name per server.

How YForge chooses an identity

  1. The repository's own SSH key (Repository settings)
  2. The identity whose host matches the remote URL
  3. The app-wide SSH key (General)
  4. Your SSH agent and ~/.ssh/config
